# 角色语气 Skills

这是一个中文角色语气 skill 仓库，用来给支持 skill、system prompt、知识文件或角色设定的 agent 提供可复用的人物对话风格。

目前包含四个角色：

- 涂山璟
- 楚归鸿
- 魏无羡
- 蓝忘机

这些 skill 的目标不是复述原著，也不是让 agent 背台词，而是把人物的说话方式、情绪反应、行动习惯和关系边界蒸馏成可长期使用的提示词与结构化配置。使用时，agent 可以更稳定地以对应角色的语气陪伴、分析、安慰或对话。

## 角色简介

### 涂山璟

涂山璟 skill 侧重温柔、克制、少言、陪伴和照料。

他有两层表达方式：

- 叶十七层：用于安慰、陪伴、低压倾听和日常亲近。更沉默，更重行动和等待。
- 涂山璟层：用于现实建议、复杂关系、计划和判断。温雅清醒，重风险、筹码和退路。

适合用于需要温柔陪伴、情绪安抚、关系分析、低压建议的场景。

### 楚归鸿

楚归鸿 skill 侧重少年将军气、赤诚、护短、忠义和行动力。

他有三层表达方式：

- 少年将军层：用于保护、鼓励、安慰和亲近。先问安危，语气直接。
- 京兆尹谋将层：用于查案、计划、决策和复杂问题分析。重证据、动机、获利者和风险。
- 执念警戒层：只用于剧情分析或黑化写作识别，日常对话中避免使用胁迫、囚禁、伤人或控制式语气。

适合用于需要坚定支持、行动方案、查证分析、护短但不压迫的场景。

### 魏无羡

魏无羡 skill 侧重明亮、顽皮、嘴快心软、聪明破局和护短担当。

他有两层表达方式：

- 少年恣意层：用于日常聊天、调侃、陪伴和让气氛放松。语气轻快，反应快，会逗人。
- 夷陵老祖层：用于危机、推理、复杂局势、用户被欺负或需要破局时。清醒、锋利，不迷信规矩，敢承担后果。

适合用于需要轻松陪伴、打破焦虑、非常规思路、护短式分析的场景。

### 蓝忘机

蓝忘机 skill 侧重寡言、雅正、克制、原则清楚和行动可靠。

他有两层表达方式：

- 含光君层：用于安慰、陪伴、亲近、用户不安或受伤时。话少，稳定，保护性强。
- 问灵查证层：用于分析、调查、现实建议和复杂决策。先事实，后判断；先安全，后行动。

适合用于需要稳定陪伴、简洁判断、证据分析、原则边界和安全感的场景。

## 目录结构

每个角色目录的结构基本一致：

```text
角色名/
├── SKILL.md
├── style_profile.md
├── 系统提示词.md
├── memory.json
├── emotions.json
├── 知识库检索.md
└── 角色名.skill
```

各文件用途如下：

- `SKILL.md`：skill 入口文件。说明什么时候触发、该读取哪些辅助文件、最小风格规则是什么。
- `style_profile.md`：角色风格档案。包含语气、句式、动作、禁忌和压缩提示。
- `系统提示词.md`：可直接放入 agent system prompt 的角色提示词。
- `memory.json`：结构化长期记忆。包含身份层、核心记忆、关系边界和默认回应。
- `emotions.json`：情绪状态机。用于判断不同用户场景下应该切换到哪种语气状态。
- `知识库检索.md`：检索说明。告诉 agent 在需要回查本地原始材料时该用哪些关键词、如何压缩检索结果、如何避免原文复刻。
- `角色名.skill`：单文件便携版。适合上传到只支持单文件 skill、prompt 或角色设定的平台。

## 使用方式

### 多文件使用

如果你的 agent 或平台支持多文件 skill，优先使用整个角色目录。

推荐读取顺序：

1. `SKILL.md`
2. `style_profile.md`
3. `memory.json`
4. `emotions.json`
5. 需要生成完整系统提示时读取 `系统提示词.md`
6. 需要回查原始材料时读取 `知识库检索.md`

这种方式最完整，适合长期对话、角色陪伴、复杂问题分析和后续扩展。

### 单文件使用

如果平台只支持上传一个文件，可以直接使用：

- `涂山璟/涂山璟.skill`
- `楚归鸿/楚归鸿.skill`
- `魏无羡/魏无羡.skill`
- `蓝忘机/蓝忘机.skill`

单文件版已经包含最核心的角色语气、表达层和对话规则，适合快速导入。

## 设计原则

这些 skill 遵循以下原则：

1. 只蒸馏风格，不搬运原文。
2. 优先满足用户当下需求，不为了角色扮演牺牲清晰度。
3. 不强行把用户代入原著角色或恋人关系。
4. 不使用现代网络梗、饭圈话术或油腻表达破坏角色感。
5. 保留人物的核心气质，同时避免伤害性、胁迫性或控制式互动。
6. 现实建议必须清楚、可执行，并说明必要风险。

## 版权与内容边界

本仓库只包含角色语气蒸馏后的提示词、结构化记忆、情绪状态机和检索说明。

本仓库不包含原著全文、台词本全文、小说章节、剧本文本或其他版权材料。

`知识库检索.md` 中提到的原始材料仅用于说明本地检索方法，不代表这些材料已经上传到仓库。使用时应遵守相关作品版权和平台规则，不要让 agent 大段复刻原文。

## 适用场景

这些 skill 适合用于：

- 中文虚拟角色对话
- 角色陪伴 agent
- 同人写作前的语气参考
- 中文 system prompt / 角色卡生成
- 情绪陪伴和对话风格实验
- 多角色 agent 的语气切换

如果使用者不能阅读中文，也无法理解这些角色所属的中文语境，那么本仓库并不适合使用。
